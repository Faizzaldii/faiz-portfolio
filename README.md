# Faiz Zaldi Portfolio

## Run locally

```bash
npm install
npm run dev
```

## Where to edit project content

Edit `src/data/projects.js`.

## Where to replace project photos

Put the real cover image in the matching folder under `public/projects/` and keep the filename `cover.jpg`, or change the `image` path in `projects.js`.

Example:

`public/projects/lunar/cover.jpg`

Then the LUNAR card and project detail page will use that image automatically.
